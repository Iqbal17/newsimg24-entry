A program that draws "The World in One Day": a newspaper front page that sums up Tuesday 24 November 2026 in one picture. Eight story panels, each with a hand-drawn icon and a short headline — Ukraine sinks a Russian warship, COP31 ends with no deal, a factory fire kills 24 in Indonesia, 14 killed in Kyiv region strikes, the ICJ rules Myanmar committed genocide, Alcaraz wins the ATP Finals, the World Chess title defence begins, and NATO vows space defence — plus a footer line for the UK hosting the 2035 Women's World Cup. Pure Python standard library: the PNG, the bitmap font and every icon are built in code, so the output is byte-for-byte deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
